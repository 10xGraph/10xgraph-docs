Every page in this section is a runnable example from the [10xGraph repository](https://github.com/10xGraph/10xGraph/tree/main/agentflow/examples). Each page explains what the example builds, walks through the code file by file, and ends with the full source of every file in tabs, so you can read it here or copy it straight into your project.

## Run any example

```bash
git clone https://github.com/10xGraph/10xGraph.git
cd 10xGraph/agentflow
pip install "10xgraph[openai,google-genai,anthropic]"
cp examples/.env.example .env   # add the API key for the provider the example uses
python examples/quickstart/quickstart.py
```

Each page lists the extras and the one environment variable its example needs. The model string is written in each file, so changing provider is a one-line edit.
